Weaver: tree-sitter, Git, and conversations weave narratives

A persistent map of code, history, and investigation so agents do not have to rediscover the same relationships.

April 10, 20261 min read
weavertree-sitteragentscodebase-memory

“Someone has to be using tree-sitter for codebase search.”

That led me to Codebase-Memory, which led me to the idea of linking symbol history, user-linked data, synthetic data, and…

Honestly, seeing my agents ripgrep the same thing constantly while eating tokens, I wanted to provide a map of known relationships. It could remove the need for repeated ad hoc investigations while exposing those investigations to new, graph-like perspectives.

That is pretty much the purpose of Weaver.
