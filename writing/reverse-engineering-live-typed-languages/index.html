Reverse engineering live typed languages

Heap Lens began with an urge to recover a live application's object model without treating it like a GUI.

February 7, 2025
heap-lensreverse-engineeringagents

Ever get the urge to pull the live object model out of a typed language?

Want to drive a local agent to use an application without relying solely on GUI cues, an official API, or an intercepted data stream?

I ripped this intent out of some libraries I’d made, clean-room, and packaged it for reuse: something an LLM could even call on for investigations or live interactions.

For now, its name is Heap Lens. I can’t think of a better way to name something that observes live heaps without interference. It is not a debugger.
